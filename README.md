# O.P.S.扩展改装件 1.2.3

轨道精准攻击的两种可选改装件，在管理器中二选一。

- **自动装弹机**：基础冷却时间 40 秒，呼叫时间固定 2 秒，不受呼叫时间加成及环境修正影响。
- **待发弹药架**：基础补充时间 70 秒，呼叫时间固定 2 秒，初始储存 3 发，可连续发射。首次消耗后开始逐发补充，连续发射不重置补充进度，满库存停止计时，没有短装填限制。

冷却与补充时间仍受游戏内升级及环境冷却修正影响。储存版使用原生次数角标、补充进度条和详细冷却倒计时。

唯一前置为 **Bingus Shared Loader（BSL）v15+**，无需 HD2Runtime。请停用旧版及诊断模组，导入本压缩包，选择改装件、部署并完整重启游戏。

本正式版采用用户确认正常的 1.2.3 性能优化实现：固定指针链定位 HUD，限量查找并退避；每次更新最多读取 256 KiB、查询 128 次，不使用全地址空间扫描。

已知限制：呼叫倒计时及“着陆”提示与实际命中有轻微错位。用户已接受此限制，显示对齐工作暂时搁置；本版不包含后续显示实验及原生文本重建调用。

本模组涉及平衡性修改，**不建议在多人房间使用**。


## 下载与安装

正式安装包：[O.P.S.扩展改装件-1.2.3.zip](build/O.P.S.扩展改装件-1.2.3.zip)。直接导入管理器，无需解压。

## 从源码构建

需要 Python 3.10+，仅使用标准库。在仓库根目录执行：

```powershell
python tools/build_variants.py
```

生成的 ZIP 位于 `build/`，包含互斥的两种改装选项。构建不需要启动游戏，也不需要 HD2Runtime SDK。

离线回归检查需要 Windows 和本机游戏自带的 `lua51.dll`。设置 `HD2_GAME_ROOT` 为游戏安装目录后，运行 `tools/verify_variants.py`、`tools/verify_bsl_package.py`、`tools/verify_storage.py` 等检查。这些检查不能替代游戏内测试。

## 版本与兼容性

1.2.3 是此前经游戏内测试确认的稳定实现，本次仅整理发布文件，没有调整玩法。程序校验适配的游戏二进制指纹，游戏更新后可能拒绝加载；不代表已验证所有后续游戏版本。具体指纹见 `src/local_schema.lua`。

`hd2runtime.json` 保留历史配置文件名，内容声明的唯一游戏前置为 BSL。
